Unicycle Robot Trajectory-Tracking Simulation

Unicycle trajectory-tracking project combining error-dynamics analysis, closed-loop simulation, and numerical evaluation across four initial conditions.

GitHub Repository

Main Task

  • Developed the error-dynamics formulation and MATLAB simulation for unicycle trajectory tracking.
  • Evaluated closed-loop tracking and convergence across four initial-position and heading cases.

Validation: All four cases converged toward the target pose with near-zero range error and sub-degree angular errors.

Controller Design

Differential-Drive Wheel Controller

The body-level commands \(v\) and \(\omega\) are converted directly into the right and left wheel angular speeds.

Main wheel-speed dynamics

\[ v=\frac{r}{2}\left(\dot q_R+\dot q_L\right), \qquad \omega=\frac{r}{2l}\left(\dot q_R-\dot q_L\right). \] \[ \dot q_R=\frac{v+l\omega}{r}, \qquad \dot q_L=\frac{v-l\omega}{r}. \]

Closed-loop wheel controller

\[ v=k_1\rho, \qquad \omega=k_2\alpha+k_3\phi+k_4\dot\alpha+k_5\dot\phi. \] \[ \boxed{ \dot q_{R,L} =\frac{1}{r}\left[ k_1\rho \;\pm\; l\left(k_2\alpha+k_3\phi+k_4\dot\alpha+k_5\dot\phi\right) \right] } \]

Use \(+\) for the right wheel and \(-\) for the left wheel.

Simulation Results

Four Simulation Cases

Each case is shown on its own row so that its animation and static trajectory-and-error result remain easy to inspect independently.

Polar Error Coordinates

ρ
Distance to target: straight-line distance from the robot to the target position.
α
Heading-to-target angle: signed angle from the robot's forward direction to the line of sight toward the target.
φ
Approach-angle error: signed angle from the line of sight to the desired final heading at the target.

The desired heading error is α + φ = θd − θ. Subscript 0 denotes an initial value; θ0 is the robot's initial heading. Angular values are in degrees.

Additional Numerical Test

Large-Angle Test

A 110° initial heading-to-target angle was evaluated using the same model and controller parameters. This is an additional test, separate from the four initial conditions documented in the course report.

110° Heading-to-Target Test

ρ0 = 30, α0 = +110°, φ0 = −80°, θ0 = 60°

Numerical result at 25 s: ρ = 0.000549, |α| = 0.372°, and |φ| = 0.851°. The range briefly increases to 30.137 during the large heading adjustment before decreasing toward zero.
