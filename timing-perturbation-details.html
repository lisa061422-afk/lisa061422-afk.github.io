Timing Perturbations · Project 1

Linear Systems with Timing Perturbations

A two-tank MATLAB reproduction illustrating how dynamic feedback compensates for delayed control updates while preserving the nominal state at scheduled update times.

Hydro-tank model

The state vector is x = [h1, h2]T, where each state is a physical water level and must remain nonnegative. The pump commands form the input vector u. Between control updates, the continuous-time LTI model is propagated with an exact zero-order-hold transition.

ẋ(t) = Ax(t) + Bu(t)
A = [−0.0146   0.0146;  0.0146  −0.0272]
B = [64.9351  0;  0  64.9351]

The experiment starts from [0.10, 0.10] m and tracks the target levels [0.40, 0.23] m. Dynamic input corrections are computed after each delayed update so that the perturbed trajectory returns to the nominal trajectory at the scheduled synchronization instants.
